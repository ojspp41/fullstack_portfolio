# AI Atlas — 한솔그룹 13개 계열사 1만 명 사내 LLM 서비스

## 사용자 문제부터 제품 출시까지

기획자·디자이너가 없는 환경에서 사용자 문제를 정의하고, 입사 2개월 만에 기획·개발·테스트·운영 전 과정을 주도해 런칭했습니다. 프론트 오너로서 화면을 구현하고 Go Gateway 일부 기능과 미터링 파이프라인을 직접 구현했습니다.

## AI / LLM 제품 개발

- Generative UI의 JSON 복구·위젯 격리
- 스트리밍 마크다운 파서와 WebSocket 클라이언트 방어
- RAG·청킹·임베딩 과정 시각화
- 타 조직 Agent의 승인·실행·회수 경계
- 파일 인앱 미리보기와 DRM 처리 사본의 격리 서빙

### 운영 · 관리자 — 사용량·비용 미터링

화면 요구를 백엔드 집계로 역설계해 조회·비교 API, 사용 한도 제어, Kafka 이벤트 인입, 일배치 집계, 가격·환율 이력 관리, 대시보드·조회 훅·ExcelJS 내보내기를 연결했습니다. 신규 서비스는 `source_usages` 배열 계약으로 필터·색상·차트·엑셀에 자동 반영합니다.

## 공개 범위

실제 서비스 UI·데이터·내부 코드는 공개하지 않습니다. 아래 사례는 기술 구조와 담당 범위를 재구성한 설명이며 로컬 검증과 운영 결과를 구분합니다.
