> **담당 범위:** 원본 우선 파서·실패 입력 정제·구조 검사·위젯 오류 격리와 회귀 테스트를 구현했습니다.

## 문제 원인 · 해결 목표

- **상황:** AI 응답의 잘못된 JSON 때문에 위젯이 표시되지 않았고, 위젯 오류가 채팅 화면까지 영향을 줬습니다.
- **목표:** 정상 입력은 그대로 보존하고 실패한 입력은 복구하되, 복구할 수 없는 위젯이 있어도 채팅을 유지해야 했습니다.

## 해결 과정

1. 원본을 먼저 `JSON.parse`에 전달하고, 실패한 입력에만 코드 블록·따옴표·쉼표 등 6단계 정제를 적용했습니다.
2. 문자 정제 후 구조·괄호 균형을 검사해 다시 파싱했습니다. 문법 복구와 위젯 렌더링을 분리해 한 단계의 실패가 전체 화면으로 번지지 않게 했습니다.
3. 동기 렌더링 오류는 Error Boundary로, 비동기 작업은 별도 예외 처리로 격리했습니다. 고정 입력 40개를 전후 비교하고 실패 사례를 회귀 테스트에 남겼습니다.

## 결과

- **성공 입력:** 24/40 → 39/40. 복구율 60% → 97.5%.
- **파싱 실패:** 16건 → 1건. 위젯 오류가 발생해도 채팅 화면은 유지합니다.

### 검증 조건 · 현재 한계

동일한 40개 fixture의 테스트 결과입니다. 정상 JSON 보존과 정제 규칙의 회귀를 확인하는 기준이며, 모든 모델 응답이나 모든 JSON 오류를 복구한다는 의미는 아닙니다. 남은 실패 입력은 오류 안내 대상으로 유지했습니다.
