## 문제 원인 · 해결 목표

직원은 오류가 난 페이지와 화면 사진을 함께 남겨야 했습니다. 모든 제보가 개발 작업으로 이어지는 것은 아니어서, 서비스 안에서 먼저 접수하고 관리자가 Jira에 보낼 건을 고르도록 했습니다.

## 해결 과정

1. **제보 접수** — Go API가 원문과 페이지 링크를 MongoDB에, 사진을 비공개 MinIO에 보관합니다. 관리자는 보드에서 원문과 사진을 확인합니다.
2. **티켓 생성** — 관리자가 선택한 제보를 Atlassian MCP로 전달합니다. Jira가 이슈 키를 반환하면 사진을 올리기 전에 키부터 저장합니다. 생성 응답이 끊기면 관리자가 Jira에서 확인해 기존 티켓을 연결합니다.
3. **첨부 복구** — 전송되지 않았다고 확인된 사진만 같은 티켓에 다시 올립니다. 첨부 여부가 불확실하면 Jira의 첨부 목록을 조회하고, 결과가 확인될 때까지 재전송을 보류합니다.

## 결과

- **관리자 보드** — 격리된 DB와 로컬 MinIO에서 기존 티켓을 연결한 뒤 제보와 사진을 다시 조회해 보존을 확인했습니다.
- **별도 제보 에이전트** — Generative UI 폼은 개발 환경의 채팅과 로컬 전송 API로 검증했습니다. 개인 Jira 연결이 없는 테스트 사용자가 보낸 제보로 실제 티켓 1건과 사진 2장 첨부를 확인했습니다.
